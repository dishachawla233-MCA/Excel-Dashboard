# Excel-Dashboard
I developed a comprehensive Annual Store Report and Dashboard for Vanshika Store using Microsoft Excel, analyzing a full year of sales data. This process involved data cleaning and preparation using Excel formulas and performing segmentation analysis using PivotTables to identify trends and top-performing products. The final output was a dynamic, interactive Excel Dashboard featuring Slicers and visualizations, which provides store management with a real-time, accessible tool for monitoring performance and making data-backed decisions on inventory and strategy for the upcoming year.
